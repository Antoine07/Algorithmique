# Examen Python — consignes

Bon examen ! Si vous n'avez pas le temps de tout terminer, ce n'est pas grave. Faites de votre mieux et soignez les réponses que vous rendez.

## Épreuves et barème

- Le QCM contient 25 questions et est noté sur **25 points**. Une bonne réponse rapporte un point.
- Pour les exercices d'algorithmique, les exercices 1 à 5 valent 15 points au total et les exercices 6 à 8 valent 5 points au total. Les exercices 9 à 11 sont facultatifs et comptent comme bonus.

## Préparer les fichiers de réponse

Créer un dossier nommé `NOM_Prenom`, avec votre nom et votre prénom, contenant ces deux fichiers :

- `reponses_qcm.txt` : inscrire une réponse par ligne, par exemple `1. C` ;
- `reponses_exercices.py` : écrire les solutions Python, en séparant les exercices par un commentaire comme `# Exercice 1`. Pour le défi qui demande une explication, rédiger celle-ci dans un commentaire.

Pour les programmes à écrire, utiliser des noms de variables et des messages affichés en anglais. Dans le dernier défi fourni sous forme de code, conserver le message demandé.

## Envoyer le devoir

Compresser le dossier `NOM_Prenom` en une archive nommée `NOM_Prenom.zip`, puis envoyer cette archive à **aahlucsko@gmail.com** avec l'objet `Examen Python — NOM Prénom`.
